Rodzaje pętli w programowaniu

1. Pętla for

Opis: Pętla stosowana, gdy z góry wiemy, ile razy kod ma się powtórzyć.

Konstrukcja: for (inicjalizacja; warunek; krok) { instrukcje; }

Schemat działania:

1. Start (inicjalizacja)
2. Czy warunek spełniony?
   - Tak: Wykonaj kod -> Zmień licznik (krok) -> Wróć do punktu 2
   - Nie: Wyjdź z pętli

2. Pętla while (z kontrolowanym wejściem)

Opis: Pętla sprawdza warunek przed każdym wykonaniem kodu. Jeśli na początku warunek jest fałszywy, kod nie wykona się ani razu.

Konstrukcja: while (warunek) { instrukcje; }

Schemat działania:

1. Czy warunek spełniony?
   - Tak: Wykonaj kod -> Wróć do punktu 1
   - Nie: Wyjdź z pętli

3. Pętla do while (z kontrolowanym wyjściem)

Opis: Pętla wykonuje kod najpierw, a dopiero potem sprawdza warunek. Dzięki temu kod wykona się co najmniej raz.

Konstrukcja: do { instrukcje; } while (warunek);

Schemat działania:

1. Wykonaj kod
2. Czy warunek spełniony?
   - Tak: Wróć do punktu 1
   - Nie: Wyjdź z pętli
